What is a micro:bit? 🤖

The BBC micro:bit is a pocket-sized computer about half the size of a bank card. Children write code on a laptop, send it to the micro:bit with one click, and watch it come to life: flashing lights, games, and sensors that respond to the real world.

✨ What it can do

  • 25 red LEDs to display pictures, words and animations
  • Buttons and a shake/detect motion sensor (accelerometer)
  • Senses temperature, light and direction (compass)
  • Bluetooth radio - two micro:bits can talk to each other!

👩‍🏫 Why we teach with it

  • Instant results keep young coders hooked
  • Free, world-class lesson plans from microbit.org
  • Grows with the child: blocks today, Python tomorrow
  • Used in schools worldwide, so skills transfer

Try it at home (no kit needed)

The MakeCode editor has a virtual micro:bit in the browser, so children can practise without buying anything. Borrowable club micro:bits are available for home projects.
