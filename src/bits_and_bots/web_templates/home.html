Key Stage 2 · Ages 7-11

Code real things. Start with blocks, finish with Python.

We're a friendly coding club where children build games, gadgets and inventions with the BBC micro:bit - no experience needed, just curiosity! Based in Bishops Lydeard, Somerset.

🧩 Block coding first

Every child starts with MakeCode's colourful blocks which can be run on a real pocket-sized computer they can take home.

🐍 Then Python

When they're ready, children swap blocks for real text code using the official micro:bit Python Editor. Same board, new superpowers.

🛟 Safe by design

DBS-checked volunteers, no child data collected on this site, and a clear agreement about phones, photos and AI tools. See online safety.

💰 Affordable & inclusive

No cost (although donations welcome) and club micro:bits to buy or borrow - nobody misses out. Support us.
